# Barcode-recog-create
Модуль распознавания и создания штрих-кодов

# 1. Установка модулей

pip install -r requirements.txt

# 2. Запуск сканера
python scan.py

ПРИМЕЧАНИЕ: запустится локальный сервер по адресу: http://127.0.0.1:5000
на нем можно испытать сканер, примеры штрих кодов в папке output

# 3. Запуск генератора

python generator.py

ПРИМЕЧАНИЕ: запуститься консольное приложение, нужно будет ввести текст
который нужно перевести в штрих-код, далее полученный штрих код сохраняется
в папку output
